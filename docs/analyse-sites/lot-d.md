  - « Visites à domicile sur demande » ;
  - « Accès facilité pour les personnes en situation de handicap ».
- **À prévoir** :

  - domicile avec créneaux et communes desservies ;
  - DU avec l'année ;
  - choix entre n° Ordre et RPPS ;
  - samedi et horaires coupés ;
  - parkings avec distances, bus avec arrêt, dépose minute ;
  - maison médicale ;
  - bloc « philosophie » ;
  - galerie photos ;
  - aucune section vide ;
  - mode maintenance.
